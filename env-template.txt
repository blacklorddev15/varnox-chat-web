VARNOX CHAT - SERVER ENVIRONMENT
================================

This file has a normal name on purpose: `.env` and `.env.example` both start with a dot, and many
file managers, panels and unzip tools hide those by default.

THE SERVER READS A FILE NAMED EXACTLY `.env`. This one is just a visible copy.

How to use it:
  1. In the server root, create a new file named exactly:  .env
     (In the Pterodactyl file manager: New File, type ".env", create it.)
  2. Paste everything below the line marked CUT HERE into it.
  3. Fill in the seven blanks.
  4. Save, then Start the server.

The same content is already in the zip as `.env` - if your tooling can see dot-files you can just
upload that one and skip steps 1-2.

Values come from: Vercel -> your project -> Settings -> Environment Variables
